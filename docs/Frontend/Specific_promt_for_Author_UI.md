Application:
AI Writing IDE for long-form fiction authors.

Primary goal:
Minimize context switching while writing novels by combining:
- chapter editor
- arc/chapter management
- character/entity management
- timeline management
- plot summaries
- story knowledge base
- AI writing copilot
- plot consistency analysis

Design inspiration:
- Cursor
- VSCode
- Antigravity
- Obsidian

Visual style:
- Desktop app
- Dark theme
- IDE-like layout
- Dense but readable
- Professional writing tool, not a blogging app

Required layout:
- Top toolbar
- Left activity bar
- Dynamic sidebar
- Center rich text editor
- Right AI assistant/context panel
- Bottom status bar

Activities:
1. Story
2. Entities
3. Timeline
4. Knowledge Graph
5. Search
6. Tasks
7. Projects
8. Settings

Important domain concepts:
- Novel
- Arc
- Chapter
- Character Profile
- Character Relationship
- Timeline Event
- Plot Summary
- Context Change Proposal
- Writing Copilot Suggestion
- Consistency Warning

Main workspace should show:
- Chapter tree grouped by arcs
- Current chapter rich text editor
- AI assistant panel with:
  - instruction input
  - loaded context chips
  - suggested continuation
  - proposed context updates
- Context inspector with:
  - characters in scene
  - related timeline events
  - relevant plot summaries
  - unresolved consistency warnings

UX requirements:
- Author can write without leaving the editor.
- Author can open character/timeline/summary references beside the chapter.
- AI suggestions must be reviewable before insertion.
- AI context updates must require author approval.
- Pending inconsistencies should appear as non-blocking warnings.
- UI should support large novels with many chapters and characters.
