## 3. Architecture layers that remain consistent in the documented design

The following are **accepted architectural decisions**, not assertions that every live path was tested:

- **Bounded contexts:** Novel Platform owns authentication, novel/chapter/revision/publishing; Narrative service owns analysis proposals, entity/event/state, derived semantic memory. Standalone is an adapter, not the default system of record (`ADRS.md` 001/002/011).
- **Truth/approval boundary:** canonical confirmed events and author facts drive state projections; AI proposes but doesn't mutate canonical world state without defined approvals; preserve source evidence, revision IDs, corrections and version guards (`ADRS.md` 003/004/009; `STATE_PROJECTION.md`).
- **Async integration:** immutable revision + content hash → outbox/job → extraction → review → materialization; short transactions and idempotency, not distributed transaction involving model calls (`ADRS.md` 005/007/008).
- **Context/retrieval:** structured canon as truth, semantic retrieval as derived additional retrieval lane. `ADR-012`, `P7-03`, `P7-04` and `P7-05` specify embedding/versioning, hybrid ranking and deterministic packed context; they are not a substitute for run-specific live evidence.
- **P3 orchestration:** bounded controller loop with plan/objective, generation, accept saved **draft**, memory update and intentional completion; human-review gate when flag is ON; no auto publishing.
